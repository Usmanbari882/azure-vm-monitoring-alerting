# azure-vm-monitoring-alerting
Azure VM Monitoring and Alerting project using Azure Monitor, VM Insights, Log Analytics Workspace, Data Collection Rules, Azure Monitor Agent and Alerts.
# 🚀 Azure VM Monitoring & Alerting System

## 📌 Project Overview

This project demonstrates how to implement a complete monitoring and alerting solution for an Azure Virtual Machine using Microsoft Azure monitoring services.

The goal of this project was to monitor VM health, performance, resource usage, and configure proactive alerts for infrastructure management.

---

# 🎯 Project Objectives

- Monitor Azure Virtual Machine health
- Collect CPU, Memory, Disk and Network metrics
- Configure Azure Monitor
- Enable VM Insights
- Implement Data Collection Rules
- Configure Azure Monitor Alerts
- Understand Cloud Infrastructure Monitoring

# ⚙️ Implementation Steps

## 1. Azure VM Creation

Created Linux Virtual Machine:

- OS: Ubuntu Linux
- Region: Central US
- Resource Group: rg-cloudengineer-production

---

## 2. Monitoring Configuration

Enabled:

- VM Insights
- Azure Monitor Agent
- Data Collection Rule

Configured monitoring for:

- CPU Utilization
- Memory Usage
- Disk Performance
- Network Traffic

---

## 3. Alert Configuration

Created alerts for:

- VM Availability
- High CPU Utilization

Notification configured through Azure Monitor Alerts.
